# Fotos Reales — Landing Page Instalación Starlink y Redes Biobío

Para reemplazar los espacios de muestra por tus **fotos reales de instalaciones en terreno**, simplemente guarda cada foto con el **nombre exacto** indicado abajo dentro de esta misma carpeta (`src/assets/servicios/instalacion-starlink-biobio/`) y vuelve a compilar (`npm run build` o `node scripts/push-auto.cjs`). No necesitas tocar ningún archivo de código.

> **Recomendación:** Fotos horizontales (proporción 3:2 o 16:9, mínimo 800 px de ancho, formato `.webp` o `.jpg` convertido a `.webp`) y sin patentes ni direcciones exactas visibles.

## Lista exacta de archivos

1. **`hero.jpg`** — Foto principal (Hero) de una instalación Starlink en altura en parcela/casa del Biobío.
2. **`montaje-mastil-starlink-biobio.webp`** — Montaje de antena Starlink Standard Gen 3 o Mini en mástil reforzado en techo/altura librando árboles.
3. **`canaleta-cableado-estructurado-limpio.webp`** — Trabajo limpio con canaletas PVC / cableado estructurado Cat6 prolijo (cero cables sueltos).
4. **`camara-poe-porton-parcela.webp`** — Cámara IP PoE instalada en portón de entrada, poste o perímetro de parcela.
5. **`rack-router-wifi6-instalacion.webp`** — Ordenamiento de rack, patch panel o instalación limpia de router Wi-Fi 6 / Mesh interior.
6. **`enlace-fibra-drop-vecinos-biobio.webp`** — Tendido de fibra óptica drop o enlace exterior blindado compartiendo conexión entre dos viviendas.
7. **`caja-estanca-ip65-conduit-exterior.webp`** — Caja estanca IP65 / tubería conduit exterior sellada contra lluvia y viento del sur.
